# ListaTarefasApp

Aplicação web simples para gerenciamento de tarefas do dia a dia.

## Sobre o Projeto

O ListaTarefasApp permite que os usuários organizem suas rotinas através do cadastro, listagem e controle de tarefas pendentes ou concluídas, facilitando a produtividade e a gestão do tempo.

## Funcionalidades

* Cadastro de novas tarefas.
* Listagem e visualização das tarefas cadastradas.
* Controle de status (pendente / concluída).
* Remoção de tarefas do sistema.

## Tecnologias Utilizadas

* PHP
* HTML / CSS
* JavaScript

## Como Executar

1. Certifique-se de ter um ambiente de servidor local configurado com suporte a PHP (como XAMPP, WampServer ou Docker).
2. Clone este repositório ou faça o download dos arquivos no diretório raiz do seu servidor web (ex: `htdocs` ou `www`).
3. Acesse o projeto através do seu navegador no endereço local correspondente (ex: `http://localhost/ListaTarefasApp/`).
